## Problèmes Critiques — P1

### P1-1 : Métadonnées manquantes sur 3 pages publiques ✅ Corrigé
**Fichiers concernés :** `app/contact/page.tsx`, `app/mentions-legales/page.tsx`, `app/politique-confidentialite/page.tsx`
**Impact :** Les moteurs de recherche utilisaient le title/description génériques du root layout pour ces pages.
**Correction appliquée :** Export `metadata` ajouté avec title, description et directives robots adaptées. Les pages légales (mentions, confidentialité) sont marquées `noindex` car elles n'apportent pas de valeur SEO directe.

### P1-2 : Sitemap statique obsolète et incomplet ✅ Corrigé
**Fichier concerné :** `public/sitemap.xml` (supprimé)
**Problèmes :**
- `lastmod` datait de `2024-10-31` — plus d'un an de retard
- Contenait des ancres (`/#services`, `/#apropos`) qui ne sont pas des URLs canoniques indexables
- N'incluait pas les 14+ pages publiques du site (offres, blog, à-propos, etc.)
**Correction appliquée :** Création de `app/sitemap.ts` dynamique couvrant toutes les routes statiques.

### P1-3 : robots.txt statique remplacé par version programmatique ✅ Corrigé
**Fichier concerné :** `public/robots.txt` (supprimé)
**Problème :** La version statique n'interdisait pas l'exploration des routes d'administration et d'API.
**Correction appliquée :** Création de `app/robots.ts` avec règles explicites (`disallow: ["/admin/", "/api/", "/auth/", "/dashboard/"]`).

## Recommandations — P2

### P2-1 : Données structurées JSON-LD manquantes
**Impact :** Absence d'éligibilité aux rich snippets Google (Knowledge Panel, Local Business, FAQ).
**Action recommandée :** Ajouter dans `app/layout.tsx` un script JSON-LD de type `Organization` + `LocalBusiness` :
```json
{
  "@context": "https://schema.org",
  "@type": ["Organization", "LocalBusiness"],
  "name": "Odillon",
  "description": "Cabinet de conseil en ingénierie d'entreprises",
  "url": "https://www.odillon.fr",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Libreville",
    "addressCountry": "GA"
  },
  "telephone": "+241117475474",
  "email": "contact@odillon.fr"
}
```

### P2-2 : URLs canoniques non déclarées explicitement
**Impact :** Risque de contenu dupliqué si le site est accessible via `http://`, `odillon.fr` ET `www.odillon.fr`.
**Action recommandée :** Ajouter `alternates: { canonical: "https://www.odillon.fr/[path]" }` dans chaque export `metadata`.

### P2-3 : Descriptions génériques sur deux offres
**Pages concernées :** `/offres/communication`, `/offres/formations`
**Problème :** Les descriptions actuelles sont encyclopédiques ("La communication est l'ensemble des interactions...") plutôt qu'orientées valeur client.
**Action recommandée :** Réécrire pour cibler les besoins des entreprises gaboniennes et inclure des mots-clés métier pertinents.

### P2-4 : Sitemap dynamique non couvrant les articles de blog
**Impact :** Les articles publiés dans Supabase ne sont pas soumis à l'indexation via le sitemap.
**Action recommandée :** Étendre `app/sitemap.ts` pour interroger Supabase et inclure les slugs d'articles :
```typescript
const { data: articles } = await supabase.from("articles").select("slug, updated_at").eq("published", true)
```

### P2-5 : Métadonnées de la Photothèque
**Page concernée :** `/phototheque`
**Problème :** La page est un Client Component (`"use client"`) — les métadonnées ne peuvent pas être exportées directement.
**Action recommandée :** Créer `app/phototheque/layout.tsx` avec l'export `metadata` correspondant.

## Opportunités — P3

### P3-1 : Schéma Breadcrumb pour les pages Offres
Les sous-pages `/offres/gouvernance` etc. bénéficieraient d'un fil d'Ariane JSON-LD pour améliorer l'affichage dans les SERP et faciliter la navigation.

### P3-2 : Schéma FAQ sur la page Accueil
La section `FaqHome` est un candidat idéal pour un schema `FAQPage` permettant d'occuper plus d'espace dans les résultats de recherche.

### P3-3 : Attribut `hreflang` si expansion multilingue
Si une version anglaise est envisagée (pour les investisseurs étrangers au Gabon), des balises `hreflang` devront être ajoutées dès le départ.

### P3-4 : Amélioration des `aria-label` sur les boutons d'icônes
Certains boutons d'action contenant uniquement des icônes manquent d'attributs `aria-label`, ce qui nuit à l'accessibilité et indirectement au SEO (Core Web Vitals / accessibilité).

### P3-5 : Page `/a-propos` — OpenGraph image spécifique
Actuellement, toutes les pages partagent la même image OG générée dynamiquement. Une image spécifique pour `/a-propos` (avec photo d'équipe) améliorerait le CTR sur les réseaux sociaux.
